# 📈 Analítica Predictiva — Recursos, Teoría y Práctica en Python

¡Bienvenido/a a este repositorio! 👋 

Este espacio ha sido creado para compilar y compartir información útil, material de estudio y recursos prácticos relacionados con el curso de **Analítica Predictiva**.

El contenido está **abierto a cualquier persona** interesada en aprender, repasar o profundizar en el uso de técnicas predictivas y modelos de Machine Learning aplicados al análisis de datos.

---

## 📚 ¿Qué encontrarás en este repositorio?

* 📄 **Documentación del Curso:** Guías, diapositivas, lecturas recomendadas y referencias para complementar el aprendizaje.
* 🧠 **Bases Teóricas:** Resúmenes claros y explicaciones conceptuales sobre los algoritmos, fundamentos estadísticos y metodologías de evaluación.
* 🐍 **Ejemplos Prácticos en Python:** Cuadernos de Jupyter (`.ipynb`) y scripts con código explicado paso a paso, aplicando librerías como `pandas`, `scikit-learn`, `statsmodels`, `seaborn`, entre otras.

---

## 🛠️ Contenido Temático (Ejemplo de Estructura)

- [x] **Introducción a la Analítica Predictiva:** Conceptos clave y preparación de datos.
- [x] **Modelos de Regresión:** Regresión Lineal Múltiple, Regularización (Lasso, Ridge).
- [x] **Modelos de Clasificación:** Regresión Logística, Árboles de Decisión, Random Forest, XGBoost.
- [x] **Evaluación de Modelos:** Métricas (RMSE, MAE, ROC-AUC, Matriz de Confusión) y validación cruzada.
- [x] **Series de Tiempo:** Conceptos básicos y modelos de pronóstico.
